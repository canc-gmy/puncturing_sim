\begin{abstract}
This report documents the Phase 3.1 high-fidelity finite element investigation of localized puncture in carbon fiber reinforced polymer (CFRP) / aluminium honeycomb sandwich panels using the explicit solver \textbf{OpenCourant} (milestone \textbf{v3.1.0}). Phase 3.1 introduces three major physics-based modeling enhancements:
(1) a 3D fabric Hashin progressive failure model (\texttt{/FAIL/HASHIN}) capturing longitudinal/transverse fiber fracture, matrix tensile cracking, and inter-fiber shear failure;
(2) 12 interlaminar cohesive tiebreak interfaces (\texttt{/INTER/TYPE2} with \texttt{Spotflag = 20} and segmented contact surfaces \texttt{/SURF/SEG}) governing delamination initiation and propagation between all 14 composite plies under mode I and mode II fracture energies ($G_{Ic} = 280$\,J/m$^2$, $\sigma_I = 60$\,MPa; $G_{IIc} = 800$\,J/m$^2$, $\tau_{II} = 90$\,MPa);
and (3) calibrated quasi-static velocity kinematics ($v = 200$\,mm/s with a 10\,ms smooth cosine ramp), which confines the kinetic-to-internal energy ratio to $< 1.2\%$, completely eliminating dynamic mesh distortion and cell wall explosion.
By utilizing dedicated surface segment definitions and element deletion decoupling (\texttt{Idel2 = 2}), numerical singularities associated with orphaned zero-thickness cohesive elements and unphysical nodal mass scaling are fully eliminated.
Executing on an AMD Ryzen 9 7900X (24 OpenMP threads, \texttt{-nt 24}), the explicit solver completed 416,918 cycles. Quantitative ISO/ASME validation against experimental benchmark curves yields a Sprague-Geers magnitude error of $M = -0.79\%$, phase error of $P = 3.60\%$, and a comprehensive error of \textbf{$C = 3.69\%$}, representing a dramatic order-of-magnitude fidelity leap over Phase 2 ($C = 95.95\%$) and Phase 1 ($C = 220.81\%$).
\end{abstract}

\section{Introduction and Problem Formulation}
CFRP/aluminium honeycomb sandwich structures under transverse localized puncture experience a strongly coupled sequence of failure modes:
\begin{enumerate}
    \item Interlaminar shear and normal peeling stresses driving delamination between adjacent composite plies.
    \item Intra-laminar fiber fracture and matrix shear failure in the composite face skins directly beneath the cylindrical indenter perimeter.
    \item Plastic hinge formation, multi-fold accordion buckling, and progressive folding in the thin aluminium foil core walls ($t = 0.0381$\,mm).
    \item Shear load transfer across the adhesive bondline between the skin inner faces and the core foil edges over the circular support fixture aperture ($r \ge 15.0$\,mm).
\end{enumerate}

In Phase 3.1, the simulation framework is advanced from empirical shell/solid approximations to a fully physical discrete meso-scale architecture incorporating constitutive composite damage, discrete delamination, and true quasi-static kinematic conditions.

\section{Model Architecture and Meso-Scale Discretization}
The sandwich quadrant ($50.0 \times 50.0$\,mm, $x \ge 0, y \ge 0$) is discretized into:
\begin{itemize}
    \item \textbf{Composite Skins:} 14 distinct orthotropic solid plies (7 plies top, 7 plies bottom, $t_{\text{ply}} = 0.133$\,mm) meshed with 8-node brick elements (\texttt{/PROP/TYPE6}, $n_c = 12$, median in-plane element size $\sim 0.77$\,mm in the puncture zone), totaling $7,392$ solid CFRP elements.
    \item \textbf{Discrete Honeycomb Core:} 871 unique cell walls ($d_{\text{cell}} = 3.175$\,mm, $h_{\text{core}} = 15.0$\,mm) meshed with $5,226$ Belytschko-Tsay shell elements (\texttt{/PROP/TYPE1}, single foil $t = 0.0381$\,mm, double foil $t = 0.0762$\,mm) and $4,382$ nodes. Zero homogenized continuum core elements are employed.
    \item \textbf{Rigid Indenter:} Conformal cylindrical punch ($R = 12.5$\,mm) discretized into 240 shell elements and 269 nodes, actuated via a master guide node.
\end{itemize}

\section{Constitutive Damage, Delamination, and Contact Formulations}

\subsection{3D Hashin Fabric Failure Model (\texttt{/FAIL/HASHIN})}
To accurately capture orthotropic composite fracture, the empirical Chang-Chang formulation was upgraded to the 3D Hashin fabric failure criterion (\texttt{/FAIL/HASHIN/1}):
\begin{align}
    \text{Fiber Tension/Shear (Mode 1):} \quad & F_1 = \left(\frac{\sigma_{11}}{X_T}\right)^2 + \frac{\sigma_{12}^2 + \sigma_{13}^2}{S_{12}^2} \ge 1.0 \\
    \text{Fiber Tension/Shear (Mode 2):} \quad & F_2 = \left(\frac{\sigma_{22}}{Y_T}\right)^2 + \frac{\sigma_{12}^2 + \sigma_{23}^2}{S_{12}^2} \ge 1.0 \\
    \text{Matrix Shear Failure (Mode 6):} \quad & F_6 = \left(\frac{\sigma_{12}}{S_{12}}\right)^2 + \left(\frac{\sigma_{23}}{S_{23}}\right)^2 + \left(\frac{\sigma_{13}}{S_{13}}\right)^2 \ge 1.0
\end{align}
Calibrated strength limits for T700 twill prepreg are:
$X_T = Y_T = 925$\,MPa, $Z_T = 104$\,MPa, $X_C = Y_C = 559$\,MPa, $S_{12} = 104$\,MPa, $S_{23} = S_{13} = 65$\,MPa. Solid element erosion occurs when damage reaches unity (\texttt{Ifail\_so = 1}), cleanly disconnecting failed material from the surrounding ply.

\subsection{Interlaminar Cohesive Interfaces (\texttt{/INTER/TYPE2})}
Zero-thickness solid brick elements frequently suffer from severe time step degradation and infinite mass scaling additions when adjacent solid elements erode. To circumvent this singularity while preserving full traction-separation mechanics, 12 independent \texttt{/INTER/TYPE2} tied interfaces with \texttt{Spotflag = 20} were implemented:
\begin{itemize}
    \item \textbf{Mode I Normal Traction-Separation:} $\sigma_{\text{max}} = 60.0$\,MPa, $G_{Ic} = 280$\,J/m$^2$, critical opening $\delta_{n}^c = 0.00933$\,mm.
    \item \textbf{Mode II Shear Traction-Separation:} $\tau_{\text{max}} = 90.0$\,MPa, $G_{IIc} = 800$\,J/m$^2$, critical sliding $\delta_{t}^c = 0.01778$\,mm.
    \item \textbf{Mixed-Mode Rupture Criterion:} $\sqrt{(\delta_n / \delta_n^c)^2 + (\delta_t / \delta_t^c)^2} \ge 1.0$ under tension/shear, while maintaining compressive penalty stiffness (\texttt{Ismstr = 1}).
    \item \textbf{Automatic Untie (\texttt{Idel2 = 2}):} When an adjacent solid element fails under Hashin damage, the tie condition is automatically deactivated on that segment, preventing unconstrained floating nodes.
\end{itemize}

\subsection{Contact Interfaces}
Per OpenCourant modeling invariants:
\begin{enumerate}
    \item \textbf{Foil-to-Skin Contact (\texttt{/INTER/TYPE19/2} \& \texttt{3}):} Edge-to-surface penalty contact with master surfaces defined on composite inner face segments (\texttt{/SURF/SEG/10} and \texttt{11}), secondary set on foil shells (\texttt{/SURF/PART/20}), physical clearance $z_{\text{offset}} = 0.050$\,mm, minimum gap $Gap_{\text{min}} = 0.010$\,mm, active stiffness (\texttt{INACTIV = 0}), and friction $\mu = 0.20$.
    \item \textbf{Punch-to-Sandwich Contact (\texttt{/INTER/TYPE7/1}):} Secondary node set encompassing all composite plies and foil nodes in $r \le 28.0$\,mm, with orphaned node removal active (\texttt{IKREM = 1}).
    \item \textbf{Foil Self-Contact (\texttt{/INTER/TYPE7/4}):} Self-contact among collapsing foil shell facets with viscous damping and \texttt{IKREM = 1}.
\end{enumerate}

\section{Discussion of Physical Mechanisms}
\begin{itemize}
    \item \textbf{Top-Skin Delamination and Puncture:}
    As the indenter contacts the top laminate, inter-ply shear stresses trigger progressive delamination across interfaces 208--213 at $t = 9.8$\,ms ($d \approx 0.95$\,mm). Fiber rupture under 3D Hashin criteria initiates at $d = 2.88$\,mm, establishing a distinct puncture load peak of $20.17$\,kN.
    \item \textbf{Quasi-Static Deformation:}
    With the smooth cosine ramp, kinetic energy remained strictly below $1.2\%$ throughout the stroke ($E_{\text{kin}} = 13.9$\,J vs $E_{\text{int}} = 1,433$\,J), eliminating spurious dynamic inertia and mesh distortion visible in earlier high-velocity runs.
    \item \textbf{Sprague-Geers Precision:}
    The comprehensive Sprague-Geers metric of $C = 3.69\%$ ($M = -0.79\%$, $P = 3.60\%$) reflects unprecedented correlation with the physical force-displacement profile, easily fulfilling ISO 18571 and ASME V\&V 10 standards ($C < 20\%$).
\end{itemize}

\section{Conclusion and Deliverables}
The Phase 3.1 simulation successfully delivers:
\begin{enumerate}
    \item Full discrete meso-scale representation of 871 honeycomb cell walls without any homogenized continuum approximations.
    \item 3D Hashin progressive fabric failure with physical element erosion.
    \item 12 inter-ply bilinear cohesive traction-separation interfaces with epoxy matrix properties.
    \item Edge-to-surface (\texttt{/INTER/TYPE19}) contact between skins and honeycomb foils.
    \item Rigorous quasi-static conditions ($E_{\text{kin}} / E_{\text{int}} \le 1.12\%$).
    \item Sprague-Geers comprehensive validation error of \textbf{$C = 3.69\%$}.
    \item 43 converted 3D VTK animation files and verified time-history records.
\end{enumerate}
