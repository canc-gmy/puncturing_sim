\begin{abstract}
This technical report details the high-fidelity explicit finite element investigation of localized shear puncture in a carbon fiber reinforced polymer (CFRP) / aluminium honeycomb sandwich panel subjected to indentation by a cylindrical flat punch ($\varnothing 25$\,mm) resting over a circular aperture ($\varnothing 30$\,mm). Formulated in the open-source explicit solver \textbf{OpenCourant}, release \textbf{v2.3.0} establishes constitutive core shear calibration and element erosion controls. The model incorporates a quarter-symmetric domain ($x \ge 0, y \ge 0$), polar-structured radial discretization, Chang-Chang progressive damage (\texttt{/FAIL/CHANG}), an orthotropic core formulation with shear yield (\texttt{/FUNCT/29}) and shear strain erosion limits, and safe mass scaling ($0.14\%$ added mass). Executing across 24 OpenMP worker threads, the solver completed all 151,797 cycles in $180.7$\,s ($3.0$\,min) with normal termination, resolving element inversion via a calibrated acoustic deletion threshold ($\Delta t_{\text{brick}} = 2.0 \times 10^{-8}$\,s).
\end{abstract}

\section{Introduction}
Composite sandwich panels with carbon-fiber face sheets and honeycomb cores are essential structural elements in aerospace and automotive impact-absorbing structures. Under tight aperture support conditions (where physical clearance is only $2.5$\,mm around the perimeter of a $\varnothing 25$\,mm indenter), global panel bending is heavily suppressed, and structural resistance is dominated by high-gradient through-thickness shear plugging, core cell-wall crushing, and localized perforation.

\section{Finite Element Model Architecture (v2.3)}
The 3D explicit dynamic puncture simulation is implemented in OpenCourant:
\begin{itemize}
    \item \textbf{Quarter-Symmetric Discretization:} The model exploits biaxial symmetry ($x \ge 0, y \ge 0$) spanning $50 \times 50$\,mm. Conformal quarter-polar meshing aligns with the indenter ($r = 12.5$\,mm) and die aperture ($r = 15.0$\,mm), comprising 353 nodes and 320 hexahedral elements per layer across 24 through-thickness plies (7,680 bricks, 8,825 nodes).
    \item \textbf{Exact Symmetry Boundary Conditions:}
    \begin{itemize}
        \item $X$-symmetry plane ($x = 0$): $u_x = 0, \theta_y = 0, \theta_z = 0$ (\texttt{100 011}).
        \item $Y$-symmetry plane ($y = 0$): $u_y = 0, \theta_x = 0, \theta_z = 0$ (\texttt{010 101}).
        \item Clamped lower aperture ring ($z = 0, r \ge 15.0$\,mm): fully fixed (\texttt{111 111}).
        \item Indenter master node: pure $Z$-translation (\texttt{110 111}).
    \end{itemize}
    \item \textbf{Core Shear Calibration \& Erosion Control:} In release v2.3, \texttt{/MAT/LAW28} incorporates a shear yield curve (\texttt{/FUNCT/29}) capping out-of-plane shear stress at $\tau_y = 3.48$\,MPa, paired with shear failure strain ($\gamma = 0.25$) and brick acoustic deletion (\texttt{/DT/BRICK/DEL} set to $2.0 \times 10^{-8}$\,s) to prevent negative volume locking during bottom-skin compression.
    \item \textbf{High-Performance Computing:} Executed on 24 OpenMP worker threads, completing 151,797 cycles in $180.74$\,s (3.0\,min).
\end{itemize}

\section{Conclusion}
The OpenCourant quarter-symmetric finite element framework (v2.3) successfully completes the full $16.2$\,mm penetration stroke under normal termination across all 151,797 cycles. The calibrated brick erosion threshold eliminates element inversion locking. All solver decks, python automation scripts, and VTK datasets (81 states) are fully version-controlled.
